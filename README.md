# SmartWare Operations console 

## System Overview
The SmartWare Operations Console is a dynamic, console based C# management system designed to monitor, simulate, and control real-time warehouse logistics operations. Built for high reliability and concurrent processing, the system manages inventory tracking, task assignment, real-time background analytics, and persistence. 

### Key Features
* **Menu Driven Console Interface:** Clear, interactive CLI for creating, updating, and tracking warehouse operations.
* **Real time Background Processing:** Continuous, non blocking background monitoring for stock tracking and task dispatching.
* **Event-Driven Notifications:**  event notifications for task completions, low-stock warnings, and system alerts.
* **Exception Handling:**  domain validation preventing duplicate orders, insufficient stock, and persistence errors.
* **Data Persistence & Logging:** State persistence using file storage and action logging.
